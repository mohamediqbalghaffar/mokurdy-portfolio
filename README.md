## 🛠️ Local Development & Deployment

### Run Locally:
Simply open `index.html` in any modern web browser or serve via Python / Node:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

### Deploy to Vercel:
```bash
npx vercel --prod
```
